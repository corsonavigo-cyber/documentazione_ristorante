======================================================================
5.  API
======================================================================

Le API espongono le funzionalità del gestionale tramite richieste HTTP.

Esempi di endpoint:

    /api/tavoli.php

    /api/menu.php

    /api/prenotazioni.php

    /api/ordini.php

    /api/scontrino.php


Le funzionalità specifiche vengono selezionate tramite parametri
come:

    ?type=...


Esempio:

    /api/menu.php?type=menu

    /api/ordini.php?type=oggi

    /api/scontrino.php?type=iva


======================================================================
5.1 API GENERICHE JAVASCRIPT
======================================================================

Le chiamate HTTP vengono centralizzate attraverso funzioni
riutilizzabili.

L'obiettivo è evitare di duplicare continuamente:

    fetch()
    gestione URL
    headers
    parsing JSON
    gestione errori


I parametri delle richieste vengono gestiti tramite
URLSearchParams quando appropriato.
